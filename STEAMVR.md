# Целевая платформа SteamVR

По указанию пользователя игра предназначена для SteamVR на ПК. Основной путь — Valve SteamVR Interaction System, SteamVR Input Actions и OpenVR XR Loader. При последующих изменениях сохранять этот путь и штатные модели рук SteamVR.

Целевое оборудование уточнено: HTC Vive Pro. Основной профиль контроллеров — штатные Vive Wands (`vive_controller`); профиль HMD — `vive_pro`. Курок используется для UI/щипкового захвата, боковой грип — для захвата, тачпад — для телепорта и дискретного поворота. Целевой бюджет при 90 Гц — 11,1 мс; проверять CPU и GPU отдельно на самом шлеме.

В инвентаре добавлены «Продолжить» и «Выход из игры». Выход требует повторного подтверждения. В редакторе подтверждение останавливает Play Mode, в готовом EXE вызывает Application.Quit. Для выбора можно направить контроллер или взгляд и нажать курок.

Взаимодействия должны работать с левой и правой рукой через SteamVR Hand, Interactable, Throwable, GrabPinch и GrabGrip. Эмуляция мышью/клавиатурой допустима для разработки, но не должна быть единственным способом использования функции. Самодельные оранжевые перчатки HandVisuals отключены по просьбе пользователя; не восстанавливать их и не скрывать штатные модели контроллеров.

Перед сдачей проверить на целевом шлеме: запуск SteamVR runtime, отслеживание обеих рук, телепорт на оба этажа, двери, вентиль, захват и отпускание мешка/купюр/лампочки/квитанции, диалоги, инвентарь, фонарик и окончание смены. Проверить эти же действия в готовом Windows EXE. Программные проверки FallbackHand не заменяют этот прогон.

На 28 октября 2026 года в проекте есть OpenVR loader и привязки SteamVR для Vive, Index/Knuckles, Oculus Touch и других поддерживаемых SDK устройств. Фактическая работа с конкретным устройством требует запуска SteamVR и испытания оборудования; наличие JSON-привязок само по себе её не доказывает.
