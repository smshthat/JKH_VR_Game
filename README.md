# Смена ЖКХ — Unity / SteamVR

Открыть эту папку как проект Unity **6000.0.67f1**. Основная и единственная сцена сборки: `Assets/Scenes/SampleScene.unity`. Целевой запуск — Windows x64, DX11, SteamVR/OpenVR, HTC Vive Pro. Описание управления и требований: [STEAMVR.md](STEAMVR.md).

## Структура

- `Assets/Scripts` — рабочая игровая логика; `Assets/Editor` — редакторские инструменты.
- `Assets/Art` — локальные исправления, текстура денег, риг жителя, материалы улучшений и контур подсветки.
- `Assets/Scenes` — игровая сцена и запечённые данные освещения/окклюзии.
- `Assets/SteamVR`, `SteamVR_Input`, `SteamVR_Resources`, `XR`, `StreamingAssets` — SDK и привязки устройств. Сохранять вместе с meta.
- `Packages` и `ProjectSettings` — зависимости и настройки Unity.

Для передачи исходников нужны Assets, Packages, ProjectSettings, README и STEAMVR.md. Library, Temp, Logs, .vs и автоматически созданные csproj не являются исходниками; их можно исключить из архива передачи. Не удаляйте Library/Temp при работающем редакторе.

Неиспользуемые варианты моделей, текстур и демосцен перенесены в отдельный обратимый архив `F:/jkh/unused-assets-2026-10-29`. Он не нужен игре и не должен входить в комплект сдачи. Старые копии Scripts/Editor вне Assets находятся там же в LegacyOutsideAssets.

Актуальная техническая сверка: `F:/jkh/Проверка критериев перед сборкой.md`. Программные проверки редактора не заменяют запуск на Vive Pro. Готовый EXE и аппаратные испытания должны быть проверены отдельно перед сдачей.
